윌그로우 홈페이지

사이트 이용 통계 안내

윌그로우는 공개 홈페이지와 과정 안내에서 상담 예약·전화·위치 버튼의 이용 횟수를 집계해 안내를 개선합니다. 버튼 클릭은 예약이나 등록 완료를 의미하지 않습니다.

  • 버튼 통계에는 날짜, 안내 페이지 종류, 버튼 종류, 유입 서비스 분류, 시험 클릭 여부가 저장됩니다.
  • 이 통계 기능은 이름·전화번호·입력한 상담 내용·IP 주소·전체 검색 주소를 저장하지 않으며, 쿠키나 방문자 식별자를 만들지 않습니다.
  • 같은 클릭의 중복 전송을 구분하는 임의 번호는 방문자를 구분하지 않습니다. 7일이 지난 기록은 다음 집계 요청 때 정리하며, 일별 합계는 운영 분석에 사용합니다.
  • 브라우저의 추적 거부(DNT) 또는 개인정보 보호(GPC) 신호가 있으면 이 버튼 통계를 전송하지 않습니다.

이 안내는 공개 페이지의 버튼 집계에 관한 것입니다. 사이트 방문 통계에는 Cloudflare Web Analytics도 사용합니다. 입학 신청서와 네이버 예약 서비스의 정보 처리 범위는 별도입니다.
